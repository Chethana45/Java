# ▶️ Running the Programs

Make sure Java is installed:

```bash
java --version
```

Compile a Java program:

```bash
javac filename.java
```

Run the compiled program:

```bash
java filename
```

### Example

```bash
javac add.java
java add
```

For GUI programs:

```bash
javac AWT.java
java AWT
```

or:

```bash
javac Swing.java
java Swing
```
